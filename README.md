# Selena-Ai
Groq Integrated Polymarket Betting System 
The AI-powered Polymarket sports trading engine.

Selena is built to watch the market so you don’t have to.

It continuously scans live sports markets, analyzes game progress and pricing, monitors real-time price feeds, identifies potential late-game opportunities, and can execute trades automatically.

One dashboard. Full market intelligence.

* Real-time market scanning across NBA, WNBA, MLB, NFL, CFB, NHL, Soccer & Tennis
* Live WebSocket price feeds for constantly updated market data
* Automated opportunity detection based on configurable odds and game-progress conditions
* Late-game strategy designed to focus on games nearing their expected finish
* Price verification immediately before live orders to help avoid stale or moved prices
* Dry Run mode to simulate the entire strategy without risking funds
* Live Trading mode for automated order execution
* AI copilot powered by Groq for analyzing markets and explaining opportunities
* Bankroll-aware position sizing
* Real-time statistics & performance tracking
* Telegram trade notifications
* Multi-account support
* Fully configurable strategy parameters
